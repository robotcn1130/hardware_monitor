FPS

游戏帧率，看得见

基于 Intel PresentMon 采集真实帧率，可选择跟随前台游戏，或锁定指定程序。

  • 选择列表带进程名 + 实时帧率 + 窗口标题
  • 可在帧率后附带「窗口标题 / 程序名」
  • 两个都不勾，就只留一个干净的数字
FRAME

卡顿看得见：帧时间与低帧

平均帧率会掩盖卡顿，所以同时给出帧时间与 1% / 0.1% 低帧，两个都是判断「顺不顺」的关键。

  • 帧时间：每帧平均耗时，单位毫秒
  • 1% / 0.1% 低帧：最慢那部分帧换算出的帧率
  • 全程只做 ETW 观测，不注入游戏进程、不挂钩子
TREND

历史曲线与高温告警

每个指标都留有最近 90 次采样的走势，数值右侧的迷你折线一眼看出趋势。

  • CPU / 显卡 / 硬盘温度、CPU 占用、内存都可设阈值
  • 越界时整行变红，同时在托盘提醒一次
  • 阈值可关可调，同一项不会反复弹通知
GPU

显卡参数，自由勾选

多显卡机器可以指定只显示其中一张，六项参数各自独立开关。

  • 显卡列表带完整型号名称
  • 占用 / 温度 / 显存 / 风扇 / 功耗 / 频率
  • 只显示你勾选的那几项
LAYOUT

顺序与排版，你说了算

拖动排序弹窗里上下拖动即可调整先后，另有竖版 / 横版两种排版。

  • 鼠标拖动直观调整显示顺序
  • 竖版适合侧边常驻，横版适合贴顶
  • 窗口位置与设置自动记住
LIGHT

轻量且随手可用

无边框悬浮窗，可拖动、可置顶、可调透明度，托盘图标随时唤起。

  • 无控制台窗口，安静后台运行
  • 右键悬浮窗或托盘图标即可设置
  • 支持开机自启

FAQ

常见问题

第一次运行最容易卡在这几个地方，先看看有没有你遇到的。

打不开 Windows 11 必看
  • 提示「智能应用控制已阻止可能不安全的应用」——这是 Windows 11 自带的「智能应用控制」(Smart App Control) 拦的。它只允许运行带数字签名或已经有大量用户在使用的程序，个人开发的小工具两条都不占，所以被拦。这不是中毒，也不是程序坏了。
  • 这个弹窗没有「仍要运行」按钮，只能二选一：关掉智能应用控制，或者换个方式运行。
  • 办法一（最彻底）：换带数字签名的版本。签名版的 硬件监控.exe 会被系统直接放行，什么都不用改；发布进度以仓库 Release 为准。
  • 办法二（现在就能用）：关掉智能应用控制。设置 → 隐私和安全性 → Windows 安全中心 → 应用和浏览器控制 → 智能应用控制设置 → 选「关闭」，然后重新双击即可。注意：部分旧版本 Windows 关掉之后就没法从设置里再打开（要重置系统才能恢复），所以建议先把 Windows 更新打全再操作。
  • 办法三（不想动系统防护）：装 Python 3.14 后用源码方式运行，直接绕开这项检查，详见下面一条。
  • 下面这些办法没用，别浪费时间：点「仍要运行」（根本没有这个按钮）、右键属性里勾「解除锁定」、以管理员身份运行、命令行启动、加杀毒软件白名单、以及自己做的自签名证书——微软的受信任根计划不认本地自签根证书，这是官方明确说明的。
源码运行 备选方案 免签名
  • 不想关智能应用控制的话，可以直接用源码跑——Python 解释器本身是签好名的，源码不经过这项检查。
  • 从 GitHub 仓库把源码下载下来，装好 Python 3.14 后，在源码目录依次执行：
    pip install -r requirements.txt
    pythonw hardware_monitor.pyw
  • 功能与 exe 版完全一致，只是需要自己装一次 Python。
权限 温度 / 帧率 说明
  • 为什么一启动就弹 UAC 要管理员权限？因为读 CPU 温度和主板温度要访问硬件的 I/O 端口，抓游戏帧率要开系统级的 ETW 会话，这两件事 Windows 只让管理员做。
  • 不点「是」也能跑，只是温度和帧率那几项会显示「需管理员权限」或没有数值，其余指标照常。
误报 杀毒软件 说明
  • 少数杀毒软件会对打包后的 exe 报警。原因是这类打包工具会把所有依赖塞进一个自解压程序里，行为上跟某些恶意软件很像，属于典型误报。
  • 程序不联网、不注入任何进程、不读取游戏内存，源码可自行审阅。确认无害后在杀毒软件里加白名单即可。
  • 不放心的话，可以把 硬件监控.zip 传进 VirusTotal 扫一遍再解压。
开源 MIT 许可证 源码可查
  • 本项目已完整开源，采用 MIT 许可证，仓库在 GitHub。 源码可以自己审阅、自己编译，也欢迎提 Issue 和 PR。
  • 仓库里放的是源码和必要的第三方组件，打包脚本也一并公开——想自己出一份包，按 README 里的说明跑一遍即可；不想打包也可以直接用源码运行。
Changelog

更新日志

每一版改了什么都写在这里。当前版本 v2.1.0。

v2.1.0 2026-09-13 修复与体验
  • 退出更干净：修掉了「关掉程序后任务管理器里还留着后台进程」的问题，退出时会一并收走帧率采集用到的子进程
  • 菜单可以连着勾：在「显示内容」里勾选指标时，菜单不再一点就关，可以一口气勾好几项；鼠标移开、或点一下主窗口才收起
  • 菜单不再被挡住：修好了窗口置顶时右键菜单被悬浮窗压住一部分的问题
  • 连续右键不再叠菜单：再点一次右键会先收掉上一个，不会一层层叠出来
  • 告警可以逐项关：每一项高温 / 高占用告警前面都有独立开关，不想要的直接关掉，不用把阈值调到 0
  • 能看到版本号了：右键菜单和托盘菜单底部会显示当前版本，反馈问题时方便说清楚是哪一版
v2.0.0 2026-09-13 大版本
  • 新增帧时间与低帧：除了平均帧率，还能看到「帧时间」和 1% / 0.1% 低帧——也就是最卡的那百分之一帧能跑到多少，比平均帧率更能反映真实手感
  • 新增历史曲线：每一项右侧多了一条小折线，一眼看出最近一两分钟的走势，不用盯着数字猜
  • 新增阈值告警：CPU、显卡、硬盘温度以及占用率超过设定值时，数值会变红并弹一条系统通知；同一项两分钟内不会重复打扰
  • 新增四项传感器：主板温度、硬盘温度、系统风扇转速、电池状态（台式机显示「未检测到电池」属正常）
  • 帧率采集更省：改成常驻采集，不再每两秒重新启动一次，开销更低、读数更稳
  • 新增「设置」窗口：告警开关、阈值调整、曲线开关集中在一处，菜单不再越拉越长
v1.0 初始版本 已归档
  • 桌面悬浮窗：CPU 占用 / 温度 / 频率、内存、磁盘、网络、显卡、FPS、开机时长，共 9 项
  • 竖版 / 横版两种版式，可置顶、调透明度、拖动定位、开机自启
  • 系统托盘图标动态显示 CPU 占用，右键即可勾选要显示哪些指标
